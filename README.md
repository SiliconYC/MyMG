# MyMG — 动态图形实验仓库

MyMG 用于持续开展 MG（Motion Graphics，动态图形）技术原型实验，包括程序化二维/三维动画、正交投影、运镜、动态图文排版、音画同步和自动化渲染。

**定位：** 这是实验工作台，不是面向外部客户的商用级视频制作服务。允许快速试错、独立比较方案，并把可复现的源代码逐步沉淀下来；商业完成度不是每一次实验的前置条件。

## 目录

```text
animations/       每支 MG 原型一个独立子目录
  hbm/            HBM 堆叠与 GPU 封装科普动画
packages/         以后共用的 JavaScript / TypeScript、React 等模块
package.json      根目录 npm workspaces 定义（目前无运行时依赖）
```

目前 HBM 是 **Python 程序化渲染**，不依赖 React 或 npm。日后引入浏览器动画、React、Three.js、Remotion 等技术时，通用模块应统一放在 `packages/`，不要在每个 MG 原型中重复维护。

## 协作约定

- `dev`：日常实验与代码集成分支；默认向 `dev` 提交。
- `main`：保留稳定基线；不把未经验证的实验直接合入。
- 原型应自带运行说明和依赖列表，尽可能可从源代码重新渲染。
- 仓库主要收录**源代码与必要文档**。MP4、逐帧图像、临时音频、缓存及大体积渲染结果不入库。
- 后续再逐步沉淀动画设计原则、评审记录与可复用技能，不急于提前规定整个框架。

根目录 `package.json` 只是预留的私有 npm 工作区。**无需先运行 `npm install`** 才能使用现有 HBM 原型。
