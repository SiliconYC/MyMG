# #78 / Rapier 2D 擒纵机构实验

与 `pendulum-clock` 及 PR #77 完全隔离。实验项目绝不能作为已验证机械设计引用。

- 两个动力刚体：30 个凸齿 + 轮芯（共用轮轴刚体），两片独立擒纵瓦 + 重力摆锤（共用摆轴刚体）。
- 轮轴与摆轴均通过 Rapier Revolute Impulse Joint 固定至机架；轮轴只加恒定力矩，摆轴仅受重力。
- Rapier 0.21.0 `-compat` 内联 WASM，以确保 Vite/Remotion 浏览器构建。碰撞是真实多凸体接触，非传感器。步长 1/240 s。接触冲量 = Rapier 接触力积分（力值乘步长）；多点累计冲量记录为标量，不代表有向合冲量。对穿透以 Rapier manifold 中负接触距离取最大值。碰撞次数来自碰撞开始事件，而非角度/动画步数。
- `single` 模式只保留 1 齿和左瓦，作为几何/冲量隔离夹具，不视为完整钟表。
- 页面默认标为「实验未通过物理验证」，只有连续交替 >=10 次且测试阈值达标才输出候选而非机械认证。
- 显示的叉臂与摆杆为刚体连接示意，2D 中不参与齿轮碰撞；**研究对象仅是齿面与擒纵瓦接触**。若要做整机机械干涉/制造公差验证，必须建真实三维厚度、支撑、分层与轴向避让，不能将这里的二维结果当作已解决。
- seek/rewind：从初始构型新建 Rapier World，再固定步进到指定帧；绝不修改中途刚体角度。
- 已知实验局限：初始构型固定，不做时间相关放行；初始摆角为 0.06 rad（约 3.44°），而非零。大多数失效都应保留记录而不是隐藏。

## #80：Graham 静止式擒纵几何重建（2026-10-17）

> 此节说明**新几何候选**。旧 #78 的负面实验不能因为代码更新就改成成功；必须以本分支重新运行的 Chromium/240Hz Rapier 接触实测为准。

**依据（结构原则，不包含第三方图片直接复制）：**

- 英国钟表学会，David Poole，《Drawing Clock and Watch Escapements》，版本 1.4，第三章，2011：[公开阅读参考](https://pdfcoffee.com/drawing-escapements-version-14-ds-pdf-free.html)。选用示例：齿顶直径 48、齿根直径 36、30 齿（12° 间距）、两瓦横跨 7½ 齿距（包角 90°）、锁止 1°、冲量 2°、掉齿余量 1°、齿尖厚 0.5°。
- [Graham Escapement 原始线图](https://commons.wikimedia.org/wiki/File:Graham_Escapement.svg)：齿与两侧不对称的擒纵瓦轮廓、两个共同铰轴。
- [Abbey Clock：分别画入瓦与出瓦](https://www.abbeyclock.com/aeb3.html)；[Hessmer：开源 Graham 几何参数生成器](https://hessmer.org/gears/DeadbeatEscapementBuilder.html)。

**几何构造与实现**

1. 轮轴在 `(0,0)`；齿顶圆半径 `2.4`、齿根 `1.8`。±45° 的轮齿工作点切线相交得摆轴 `(0,2.4 / cos(45°))`。单一共同坐标系，不准独立拖动/猜测瓦的位置。
2. 工作位置：左入瓦以轮心 137.5° 的齿尖落点 C 为锁止面起点；左 132.5° 的 D 决定冲量终点半径；锁止 G=以摆轴 P 为中心从 PC 逆时针转 1°；冲量终点 H=转 3° 但取 PD 半径。右出瓦：F=42.5°、E=47.5°；I 为 PF 逆时针 2°、但取 PE 半径；L 再逆时针 1°。因此双瓦绝非左右镜像的随意凸多边形。
3. 齿轮的 30 个**真实 Rapier 碰撞齿**和页面 SVG 共用相同 4 顶点齿形；齿尖 0.5° 平头；齿根、齿尖的长斜面是理想齿形的多边形近似。齿轮实心圆仅到齿根半径，不延伸覆盖整个齿槽。
4. 两瓦的锁止面在摆轴同心圆上，冲量面为直线；渲染与物理共享完全同一多边形。由于 Rapier 需要凸碰撞形状，静止圆弧用短线段离散：约 1° 弧度内弦误差小于 `0.0001 m`。没有冒充精密实物公差。
5. **审计只认可轮齿 ID 和擒纵瓦 ID 的真实接触**；轮芯、摆杆、叉臂、摆锤都不能计为擒纵节拍。浏览器 JSON 另外保留带时间、齿 ID、左右瓦、碰撞开始/结束的序列，用于识别双瓦卡死/错齿。
6. 继续用真实重力、两个固定轴旋转关节、恒定**顺时针**轮轴力矩与 240Hz Rapier。当前摆杆与叉臂仍是可见的机构连接示意，未作为实体三维碰撞体，不得宣传完整机械加工可行性。

**验收条件：** `pnpm check`、`pnpm build:portal`、在真实 Chromium 下运行 `apps/portal/qa-escapement-physics-lab.mjs`；初始无穿透；10/60 秒左右齿瓦交替锁止/释放 >= 10 次、连续正向轮转、没有明显反转/持续卡滞，方可称为候选物理可行。如失败保持「实验未通过物理验证」，记录最新失败症状和下一轮修改建议。

## Issue #80：截图复核后的真实轮体修复（2026-10-17）

用户发布页截图证明，原 `hub` 碰撞半径 = 齿根半径 `1.8`，将整只擒纵轮做成了巨大的不透明实心圆盘，难以观察轮齿与入/出瓦的接触。新实验不对实心盘贴一层「画出来的」镂空图案，而是**移除原大圆形 Collider**，替换成真实的 30 段轮辋、6 根辐条、半径 `0.24` 的小轮毂。这些可见多边形也是 Rapier 的实际凸形碰撞体，不存在隐藏圆盘。齿尖、齿根与两瓦工作面仍按 BHI Graham 近似几何构造。

此前 60s / 68 次交替数据只能证明**旧实心模型**；轮体惯量变动可能改变新模型的稳定性，必须重新进行 10s / 60s Chromium 测试，记录结果后才可继续说“候选通过”。新状态 `UNVERIFIED` 显示「采集中」，不再在未达到 10 秒时错误标记为失败。穿透显示「模型单位」，避免未经实际标定就宣称 mm 精度。页面几何全部来自动态刚体坐标，无预计算位置。
