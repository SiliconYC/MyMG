# #78 / Rapier 2D 擒纵机构实验

与 `pendulum-clock` 及 PR #77 完全隔离。实验项目绝不能作为已验证机械设计引用。

- 两个动力刚体：30 个凸齿 + 轮芯（共用轮轴刚体），两片独立擒纵瓦 + 重力摆锤（共用摆轴刚体）。
- 轮轴与摆轴均通过 Rapier Revolute Impulse Joint 固定至机架；轮轴只加恒定力矩，摆轴仅受重力。
- Rapier 0.21.0 `-compat` 内联 WASM，以确保 Vite/Remotion 浏览器构建。碰撞是真实多凸体接触，非传感器。步长 1/240 s。接触冲量 = Rapier 接触力积分（力值乘步长）；多点累计冲量记录为标量，不代表有向合冲量。对穿透以 Rapier manifold 中负接触距离取最大值。碰撞次数来自碰撞开始事件，而非角度/动画步数。
- `single` 模式只保留 1 齿和左瓦，作为几何/冲量隔离夹具，不视为完整钟表。
- 页面默认标为「实验未通过物理验证」，只有连续交替 >=10 次且测试阈值达标才输出候选而非机械认证。
- 显示的叉臂与摆杆为刚体连接示意，2D 中不参与齿轮碰撞；**研究对象仅是齿面与擒纵瓦接触**。若要做整机机械干涉/制造公差验证，必须建真实三维厚度、支撑、分层与轴向避让，不能将这里的二维结果当作已解决。
- seek/rewind：从初始构型新建 Rapier World，再固定步进到指定帧；绝不修改中途刚体角度。
- 已知实验局限：初始构型固定，不做时间相关放行；初始摆角为 0.06 rad（约 3.44°），而非零。大多数失效都应保留记录而不是隐藏。

## 可复核实验

`pnpm --filter @mymg/portal exec node qa-escapement-physics-lab.mjs` 在带浏览器的本地 Vite 预览下执行。QA 通过页面暴露的诊断桥接，在真实 Chromium WASM 引擎中独立创建全新 World，运行 10s / 60s 两段，并执行单齿、重置、跳转/单步复现；结果保存在 `output/qa-portal/escapement-physics-lab/`。

注意：「物理技术实验」与「能够持续正确运转的擒纵钟表」是两种验收口径。负结果亦正常，**不得用旧动画轨迹验证真实物理成功**。

## 本轮实验结论

**工程与真实浏览器验证通过，但 10 秒和 60 秒机械连续擒纵均未通过。** 详见 [独立 Chromium 实测指标、失败边界与后续建议](RESULTS.md)。此 Demo 是负面技术实验，不得用来证明既有钟表 MG 的物理正确性。
