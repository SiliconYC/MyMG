# 摆钟擒纵机构 · 重力与接触驱动的 3D 动画

[GitHub Pages 播放](https://siliconyc.github.io/MyMG/#/pendulum-clock)

## 机械机构（本次修正）

- 30 齿擒纵轮与分针 / 秒针显示共轴。齿轮上真实可见的后掠齿尖是碰撞检测用的齿尖；不再以“隐藏的轮齿代理点”伪造咬合。
- 两块擒纵瓦使用 **格雷厄姆静止式擒纵的同心弧锁止原理**：锁止弧以擒纵叉摆轴为圆心，齿尖触及弧面后传递约束反力，齿轮停转；擒纵叉摆到弧面末端后放行；对侧齿尖再撞击另一块擒纵瓦。
- 擒纵叉只有两根细臂，两臂分别接在擒纵瓦的背部，钟摆、擒纵叉和擒纵瓦始终为**一个共轴旋转刚体**。不存在独立电机、伸缩锥齿、装饰性复杂连杆。
- 齿轮外形、齿尖坐标、弧面坐标、径向厚度、摆轴距离来自同一个 `escapement-geometry.ts`，三维模型和接触求解不得使用不同的几何值。
- 不显示虚假的高亮齿面和人为固定的“0.006”间隙。每次锁止的距离由真正的齿尖与有限弧面计算。

## 动力学

`clock-model.ts` 使用固定的 600 Hz 积分网格生成 30 帧/秒的确定性机械状态。

- 摆杆：重力单摆方程（`-g/L·sin(θ)`）、支点粘滞阻尼以及擒纵冲量。
- 轮子：恒定驱动力矩、转动惯量与角速度阻尼。
- 接触：齿尖进入可用锁止弧时施加单向刚性止挡，轮子速度归零，锁止时不允许继续转动；摆动越过弧端解除约束。
- 冲量：轮子碰到斜面时，以有限效率将一部分撞击动能传给摆杆，其余耗散。此为**低阶非弹性碰撞近似**，并不是求解了所有刚体表面的真实法向冲量。
- 为可跳帧和网页重播，运动状态从固定初始条件积分并缓存；不会因为播放器从中间开始播放而出现不同机械状态。

在 60 秒中约每秒发生一次交替放行。每次只前进半个齿距；60 次放行对应 30 个完整齿距，即轮轴与秒针旋转一周。

**工程边界**：这是符合重力、锁止几何和动能转移基本约束的教育级模型；它不是可直接下料制造的擒纵机芯。尚未模拟齿面弹性接触、长时磨耗、油膜、轴承间隙和三维接触应力。因此不应声称经过实物精度或加工公差认证。

## 校验与播放

`pnpm check`、`pnpm build:portal` 和 `pnpm --filter @mymg/portal qa:clock`。单元测试检查 60 次实际碰撞、齿尖与同心锁止弧的零间隙、锁止轮轴速度为零、轮轴角度单调、单轴共转、确定性跳帧；浏览器测试检查 WebGL、近景与秒针。镜头仍保持固定背面长特写及简洁演示。

参考：Laurie Penman, “Clockmaking Elements: The Deadbeat Escapement”, *Horological Times*, July 2010（美国钟表学会）；[Anchor Clock Escapement](https://abbeyclock.com/anchor.html)。
