# 机械摆钟：单一 3D 机芯 / 电影式运镜

页面： https://siliconyc.github.io/MyMG/#/pendulum-clock

从上次的「左右两个平面示意板」彻底改为同一套真实 Three.js 空间几何；时钟正面、擒纵轮、锚形擒纵叉、前后错层的擒纵瓦、钟摆、开放式支架与同轴秒针共处于一套模型中。镜头连续移动，**不是** 2D 平移、比例缩放、分屏、静态画面的轻微晃动或换场。

## 运镜

- 0—5 秒：正面稍偏侧的全景，钟摆与秒针。
- 5—17 秒：相机从右侧绕到机芯背面，露出实际厚度与前后错层。
- 17—31 秒：背面靠近擒纵齿轮、擒纵叉与交替工作的两块擒纵瓦。
- 31—44 秒：沿背面从另一侧环绕机芯，观察锁止、放行、推进。
- 44—50 秒：镜头转回正面，并推近秒针，看到齿轮放行与秒针步进的一致性。
- 50—60 秒：拉回全机收束，首尾可循环。

镜头与每一个机构的坐标完全由帧号计算。前后两面用同一套网格，过程里没有镜头切换、第二模型、MP4、GIF、图片序列、CSS 假3D。

## 运动学

- 30 齿擒纵轮、左右瓦交替锁止；钟摆 2 秒往复，1 秒一个半摆。
- 每次擒纵轮释放半齿距，即 6°，60 秒转 360°。秒针与轮轴共用角度。
- 放行时间 0.18 秒以及瓦齿形状出于教学视觉表现而简化；运动学演示**不是**碰撞力学仿真或可直接加工的机械设计。
- 不使用时间计时器控制零件或相机，只使用 Remotion \`useCurrentFrame\`。

## 回归

\`pnpm check\`、\`pnpm build:portal\`，以及 Playwright 的 \`pnpm --filter @mymg/portal qa:clock\`。浏览器 QA 保存正面、侧面、背面、齿面特写与钟盘镜头截图，检测真实 WebGL、相机由正向 z 穿越到负向 z、实际推进近景、锁止及秒针的同轴同步。
