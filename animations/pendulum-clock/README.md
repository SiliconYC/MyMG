# 擺鐘擒縱系統 · 3D 接觸示意

[在 GitHub Pages 播放](https://siliconyc.github.io/MyMG/#/pendulum-clock)

## 接觸位置

一套真正的 Three.js 3D 機構，只有鐘盤、秒針、擒縱輪、細錨臂、小擒縱瓦、擺杆擺錘和必要軸承；沒有裝飾支架。

兩塊擒縱瓦為薄型帶斜面的立體楔形，不是兩個大方塊。位置不再憑美術感覺擺放，而是由 `escapement-contact.ts` 中與擒縱輪網格一致的齒面座標推算，擒縱瓦尖端緊靠對應輪齒下降斜面：鎖止時兩者模型接觸距離約 0.006 個世界單位。放行時舊瓦退出工作區，新瓦接住半齒步進後的下一齒；接觸齒面的細亮邊直接附著於**真實齒面位置**。

這是為解釋而簡化的運動學模型，非真實彈性接觸、衝量傳遞的力學模擬或可直接加工齒形。

## 攝影機

採取明顯分段的「看清 → 快速轉場 → 長時間固定觀察」，全部觀察同一套連續 Three.js 3D 模型。

- 0–6 秒：正面秒針與鐘擺（固定）。
- 6–7.8 秒：短促繞過側面到背面。
- 7.8–19 秒：背面看擒縱輪與兩塊小瓦（固定）。
- 19–20.4 秒：推近工作齒面。
- **20.4–41 秒：20.6 秒固定在同一個能同時看見兩個齒面接觸點的視角**，不再左右劇烈切換。
- 41–43.7 秒：短促繞到正面。
- 43.7–56.5 秒：正面看秒針對照。
- 56.5–60 秒：返回起始視角；循環無跳變。

## 驗收

`pnpm check`、`pnpm build:portal`、`pnpm --filter @mymg/portal qa:clock`。單元測試檢驗每秒 30 齒輪位置與瓦尖實際距離、交替鎖止、鏡頭停留；真實 WebGL 瀏覽器測試驗證入端與出端接觸點與固定鏡頭。不使用 MP4 或逐幀圖片。
