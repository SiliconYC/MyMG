# 机械摆钟：3D 擒纵机构

线上： https://siliconyc.github.io/MyMG/#/pendulum-clock

单一 React / Three.js 立体机构。只保留钟盘、秒针、前后错层的擒纵轮、锚形擒纵叉、两块擒纵瓦、摆杆、摆锤以及两个必要轴承。删去装饰性支架和机架，不使用 MP4、逐帧图片、SVG 假 3D。

## 摄影机

由 `cameraAtFrame` 唯一确定；大部分时间停在相对固定的角度缓慢微移，让观众观察结构；转场在 1 秒左右快速掠过。

- 0–4.6 秒：正面钟盘，观察秒针为什么跳动。
- 4.6–6.4 秒：迅速绕机芯右侧到背面。
- 6.4–12.2 秒：背面全景，观察锚形叉与擒纵轮。
- 12.2–13.7 秒：推到入端擒纵瓦。
- 13.7–22.4 秒：入端瓦特写，展示锁止面与冲量面。
- 22.4–23.6 秒：快速横向移动。
- 23.6–32 秒：出端瓦特写，观察接住下一齿。
- 32–33.3 秒：快速拉到背面全貌。
- 33.3–41.7 秒：整个擒纵机构交替锁止。
- 41.7–43.6 秒：绕过侧面返回钟盘。
- 43.6–51.7 秒：正面秒针验证。
- 51.7–60 秒：全貌与循环衔接。

所有特写仍然是同一套 3D 物体，不能用独立模型或画面卡片替换。楔形擒纵瓦通过真实 ExtrudeGeometry 表示两个不平行的工作面；形状为帮助理解的概念几何，并非已验证的可制造齿形。

## 运动与验收

30 齿擒纵轮，每次放行半齿距 6°；钟摆周期 2 秒，半摆 1 秒。锁止/放行/秒针来自同一 `clockAtFrame`，无需运行时计时器。动画仍是教学运动学，并非碰撞动力学。

回归：`pnpm check`、`pnpm build:portal`、`pnpm --filter @mymg/portal qa:clock`。浏览器截图覆盖正面、飞掠、背面、入端/出端瓦近景、秒针。
