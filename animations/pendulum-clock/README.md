# 机械摆钟：擒纵轮与秒针

在 \`https://siliconyc.github.io/MyMG/#/pendulum-clock\` 播放，入口同时登记在 Studio。

## 模型

- 30 齿擒纵轮，锚形擒纵叉左右擒纵瓦交替锁止。
- 钟摆周期 2 秒（半摆 1 秒），每半摆放行半齿距，即 \`360 / (2 × 30) = 6°\`。
- 秒针与擒纵轮共用角度，一个节拍前进一秒；一分钟齿轮恰好转一圈。
- 每次放行的 0.18 秒、钟摆摆角是为 MG 演示刻意放大的运动细节；这是一份离线、确定性的运动学教学动画，**不是**包含撞击、摩擦与重力的机械动力学求解器，也不是严格可加工的齿形设计。
- 由 \`clockAtFrame(frame)\` 唯一派生齿轮、擒纵叉、钟摆、秒针位置及左右锁止状态；任意帧跳转完全确定。
- Three.js 创建齿、轴、连杆、摆锤、表盘及指针几何；DOM 只做文字层。**禁止 MP4、GIF、逐帧图或视频纹理。**

## 验收

\`node --experimental-strip-types --test tooling/pendulum-clock.test.mjs\`，以及仓库 \`pnpm check\`、\`pnpm build:portal\`、真实浏览器 QA。

理想化节奏参考：古典 30 齿钟摆擒纵，60 次锁止交替为完整一圈。实际钟机可依齿形、传动比和钟摆长度不同而变化。
