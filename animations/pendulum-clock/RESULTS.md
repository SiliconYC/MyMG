# 反冲式锚擒纵验证记录

2026-10-18。对象为 `animations/pendulum-clock` 新机构；不是独立 Rapier 实验的数据。

## 固定步长与真实接触

默认 `1/1920 s`，完整积分 60 秒，共 115,200 个物理子步。初始摆角 `-0.065 rad`，之后不施加摆轴启动器、周期补踢或预定轮角。

| 测量 | 默认 1920 Hz | 减半步长 3840 Hz |
| --- | --- | --- |
| 真实交替承接次数 | 60 | 60 |
| 后段平均半周期 | 0.999172 s | 0.999179 s |
| 最大摆角绝对值 | 0.065213 rad，约 3.736° | 0.065216 rad |
| 最小轮轴角速度 | -0.193334 rad/s | -0.193399 rad/s |
| 最大齿瓦数值穿透 | 小于 `1.01e-10` 场景单位 | 小于 `1.01e-10` 场景单位 |
| 轮轴累计驱动功 | 0.0691155 J | 0.0691154 J |
| 60 秒末机械能 | 0.0206174 J | 0.0206212 J |
| 能量收支残差 | 0.00230456 J | 0.00115228 J |

负向轮速是接触求出的反冲，不是额外倒转动画。同侧每两次承接的齿号相差一齿，完整左右周期净前进一个齿距，没有跳齿。承接检查包含齿号、实际几何间隙和压缩冲量。

能量残差为 `机械能变化 - 驱动功 + 阻尼耗散 + 碰撞损失`；默认约为累计驱动功的 3.33%，减半步长后约为 1.67%，符合该离散积分的收敛趋势。这是教学用数值模型，不能把残差说成零或把它当作精密走时认证。

无驱动对照：其余参数和初始条件不变，仅令轮轴力矩为零。60 秒后机械能约为 `0.0006115 J`，驱动功为零；摆动明显衰减。持续摆动依赖轮轴供能。

## 完整实体与渲染

- 两块有限工作面与邻近真实凸齿体逐子步接受非穿透检查。
- 非工作钢体在完整 `±0.09 rad` 摆角区间内，对整个齿顶圆的连续间隙保守下界约为 `0.03153` 场景单位；所有实际摆角均在此范围内。这个安全间隙仅适用于非工作锚臂，不用于工作面。
- 1,800 个显示帧的整件锚叉轮廓与轮体无真实交叠，随机及分数帧拖动可复现。
- 实际挤出 BufferGeometry 的全部顶点位于共享二维轮廓内部或浮点边界内。锚叉轮廓不自交，工作面没有通过向外倒角增加实体。
- 独立审查以 2,500 个随机姿态对照全部 30 齿的穷举 SAT，接触集合一致；另复核了有限面端点和直接积分与冷分数帧重播的一致性。
