# 反冲式锚擒纵：共享几何与接触构造

本蓝图适用于 `#/pendulum-clock`。所有角度以 +Y 为零、顺时针为正；Three.js 两轴均绕 Z 轴转动 `-angle`。世界坐标 +Y 向上。

## 静态尺寸

| 项目 | 场景单位 / 角度 |
| --- | --- |
| 轮心 O | `(0, 0.6)` |
| 齿顶半径 R / 齿根半径 | `0.93 / 0.72` |
| 齿数 / 齿距 | `30 / 12°` |
| 锚轴 P | `(0, 0.6 + sqrt(2) × 0.93)` |
| 中性工作点 | 从 +Y 起 `-45°`、`+45°` 的齿顶圆位置 |
| 入瓦工作线相对 +X | `-10°` |
| 出瓦工作线相对 +X | `-80°` |
| 有限瓦跟的构造姿态 | 入瓦 `-0.13 rad`、出瓦 `+0.13 rad` |
| 有限瓦尖的构造姿态 | 入瓦 `+0.027 rad`、出瓦 `-0.027 rad` |
| 瓦背厚度 | 瓦跟 `0.070`，瓦尖渐薄至 `0.022` |
| 轮 / 锚叉轴向中心 | 均为 `z = -0.02` |
| 轮 / 锚叉厚度 | `0.18 / 0.12` |
| 向内倒角 | `bevelSize=0.003, bevelOffset=-0.003` |

工作线经过各自中性工作点。在所列构造姿态下旋转工作线，与轮心 O 的齿顶圆相交；将交点变回锚轴局部坐标，得到**同一条静态工作线上的有限端点**。这些姿态仅用于一次性几何构造，运行时不按摆角阈值切换接触。

入、出瓦倾角不同，接触反力对锚轴产生相反符号的力矩；相应的摆动与轮轴反冲均由力学求解得出。不能用左右镜像、相同工作方向、臂长相等或外观近似代替这一关系。

## 共享实体

`recoil-geometry.ts` 是唯一二维工作轮廓来源。

轮齿在每齿距内的四个 `(相位, 半径)` 顶点为：`(.64, .72)`、`(.975, .93)`、`(1, .93)`、`(1, .72)`。它们构成凸齿体；末尾的齿根点与当前齿尖处于相同角度。不能把它错误地闭合至上一齿距的根点，否则会产生与可见轮齿不一致的碰撞斜边。

两瓦为凸梯形，工作边固定为瓦跟—瓦尖。整件锚叉以平滑贝塞尔窄臂连接两个瓦跟，并沿相同工作边形成单一、不自交的闭合轮廓。`anchorRibOutline` 去除两侧瓦尖部分，表示其余中央钢体；它与两个凸瓦体的并集为完整锚叉。

`escapement-mesh.ts` 直接挤出上述轮廓。轮内孔、六根辐条、轴毂和真实厚度保持可见；轮轴与锚轴都穿过有孔的固定轴承。向内倒角的最大 XY 截面等于审计轮廓，面部截面向内收。测试逐顶点核查实际 BufferGeometry，不以材质高亮代替几何。

## 动力参数与单位

| 项目 | 数值 |
| --- | --- |
| 固定步长 | `1/1920 s` |
| 摆轴总转动惯量 | `1 kg m²`（集中参数） |
| 轮轴转动惯量 | `0.0008 kg m²` |
| 恒定轮轴力矩 | `+0.011 N m` |
| 摆轴线性阻尼系数 | `0.028 kg m² / s` |
| 重力矩 / 摆轴惯量 | `-9.7 sin(theta) s⁻²` |
| 物理重力 / 有效摆长 | `9.80665 m/s²` / `9.80665 / 9.7 m` |
| 场景摆长 / 长度换算 | `5.55` / `有效摆长 ÷ 5.55 m/场景单位` |
| 初始摆角 / 角速度 | `-0.065 rad / 0 rad/s` |
| 接触候选距离 | `0.0004` 场景单位，仅用于预判闭合 |

接触 Jacobian 使用米制力臂，因此记录的法向冲量为 `N s`，能量与驱动功为 `J`。接触候选距离不是保留间隙；预判冲量只限制本子步将发生的闭合，接触面仍需实际到达零间隙。初始轮角通过入瓦真实接触几何求出，而非硬编码一个看起来接近的相位。

## 固定轴接触求解

1. 由重力、阻尼与轮轴力矩推进两轴角速度。
2. 对两瓦附近的真实凸齿体检查所有分离轴，得到间隙、接触法线及正确的顶点—边接触位置。
3. 以两个固定轴的有效转动质量解非负法向冲量，等量反作用于轮轴与锚轴；不施加吸引冲量或恢复能量。
4. 积分角度，修正浮点及离散步进的几何穿透；修正不向角速度补入能量。能量残差单独统计，减半步长验证收敛。
5. 从实际几何承接及非零冲量记录对侧接力的齿号、时间和节拍。掉齿、反冲和推动没有独立时间曲线。

默认参数按力学运行结果校准有效摆长及阻尼，使节拍约为一秒、摆幅在一分钟内基本稳定。不是用预定轨迹拟合轮角。

## 连续实体审计

- 两瓦与所有可能接触的邻齿在每个物理子步接受非穿透检查；一分钟约 115,200 个子步。
- 中央钢体在 `[-0.09, +0.09] rad` 全摆角区间检查到完整齿顶圆的距离，并用局部半径上界乘相邻角样本的一半间距，保守覆盖样本之间的连续运动。每个实际摆角必须位于此认证区间。
- 整件锚叉与轮的完整轮廓另在全部 1,800 个显示帧及选定分数帧检查。通用多边形审计区分浮点接触与有内部宽度的真实交叠。
- 实际三维挤出顶点必须位于二维实体内部或其浮点边界内，避免向外倒角造成额外实体。

这些检查代替旧版“爪尖退让、始终留出大间隙”的验收条件。实际测量见 [RESULTS.md](RESULTS.md)。
