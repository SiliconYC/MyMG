# CPU/GPU · 獨立運算單元、兩種核心組織

播放：https://siliconyc.github.io/MyMG/#/cpu-gpu

原生 React + Three.js，480 幀 / 30 FPS / 16 秒。不使用 MP4、錄影貼圖或預渲染逐幀圖片。

**開場**：鏡頭只看一個獨立、沒有 CPU／GPU 身分的中性算術單元。單個白色方塊代表「輸入值」，送入算術單元執行「+1」，變成藍色後抵達獨立的結果位置。這一步不是 CPU 的特性，而是兩者都能進行的計算。

**CPU**：鏡頭連續移動到一顆具備完整矽晶粒頂面的處理器。白色任務在封裝左外側的 4×4 輸入陣列等候，四個大核心分四批完成工作。每顆藍色方塊都要穿過晶片右側邊緣，再抵達離封裝有可見間距的 4×4 結果陣列，最後穩定停下。

**GPU**：鏡頭移到另一顆完整晶片，16 個小運算通道同時處理相同類型的 16 個任務。輸入與完成區同樣放在晶片外，使用與 CPU 相同的 4×4 陣列布局。

**最後**：鏡頭拉遠，兩顆晶片各自保留已完成的完整結果，沒有硬切、突然清空或任務回退。

白→藍是抽象教學配色；「+1」不代表 CPU/GPU 只能處理算術，也不提供性能倍數或硬體核心規格主張。畫面堅守暖白留白、一段一個焦點、一次一行文字。

測試：`pnpm check`、`pnpm build:portal`，以及 Chromium 原生 WebGL 驗收 `pnpm --filter @mymg/portal qa:cpu-gpu`。
