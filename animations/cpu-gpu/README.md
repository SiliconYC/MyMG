# CPU / GPU · 每筆數值加 1

播放：`https://siliconyc.github.io/MyMG/#/cpu-gpu`

20? 不，完整時間軸為 **16 秒 / 480 幀 / 30 FPS**。原生 React + Three.js 動畫，所有幀由時間參數直接決定。

**任務：每筆數字 +1。** 白色方塊代表還沒算的輸入資料，經過晶片內核心處理後變成藍色，代表完成。第一個白色方塊**從第 0 幀開始移動**，於 64 幀到達輸出區，持續保留；此後其他 15 項任務接續進入 CPU，CPU 的 4 個大核心分批運算。鏡頭橫移至 GPU，16 個輕量運算通道同時處理同樣任務；最後連續拉遠展示兩顆晶片的完成結果。

**晶片設計：完整頂面，不是挖掉上蓋的剖切。** 兩個方形封裝都有連續的矽晶粒本體、完整頂面及少量引腳，CPU 的 2×2 大核心與 GPU 的 4×4 細小運算單元是晶粒上方**低矮、平貼的結構**。不再有金屬蓋突然移開、暗色凹坑或讓人誤以為頂部被鋸掉的幾何形態。

暖白底色，一次一行字幕；無進度儀表板、飄散粒子及裝飾網格。數量與演算速度是原理示意，不是實際跑分；WebGL 是現場繪製，不是 MP4、影片貼圖或逐幀圖片。

驗收：`pnpm check`、`pnpm build:portal`、`pnpm --filter @mymg/portal qa:cpu-gpu`。
