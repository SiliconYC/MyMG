# CPU / GPU · 共同任務、兩種核心組織

[GitHub Pages 動畫](https://siliconyc.github.io/MyMG/#/cpu-gpu)

原生 React + Three.js，420 幀／30 FPS／14 秒。所有運動由同一時間軸計算，不使用影片或圖片序列冒充。

**先讓觀眾看懂任務**：遠離 CPU/GPU 的一個獨立中性計算單元示範「輸入數值 +1」，白色立方體在**露出的實心核心表面上方**完成處理、逐漸變藍，移動到右側落點。它沒有遮蓋工作方塊的透明殼體。輸入—核心—輸出的運動使用 `flowAt`，與後續每個 CPU/GPU 工作方塊**共用相同的函式**。

**CPU**：鏡頭迅速繞行至 CPU。4 個大核心依次分 4 波計算，共完成 16 個相同任務；每項結果離開晶片，進入外部 4×4 藍色結果陣列。

**GPU**：在 CPU 完成後，鏡頭 29 幀（不到 1 秒）內帶旋轉與高度變化飛至 GPU；16 個小運算單元同步完成同類型的 16 個任務，各自送到外部結果陣列。

**鏡頭**：38° 透視攝影機（有近大遠小），依影格推算 `yaw`、`pitch`、焦點與真正的三維移動距離。原有構圖縮放曲線改換算為攝影機前後推拉，預留 30% 透視取景餘裕，避免飛越芯片時近側任務被裁切。獨立單元 → CPU 轉場約 35 幀；CPU → GPU 仍為 29 幀；最後後退展示雙晶片。保留平滑加減速、持續三維旋轉，不會傳送物件或重設任務。透視視錐、前後景比例與關鍵畫面邊界均有自動測試。

遵守「少即是多」：暖白背景、完整矽晶粒頂面，一次一條字幕。任務數、時序與芯片大小皆是原理示意，並非實際核心數或效能倍數。

測試：`pnpm check`、`pnpm build:portal`、`pnpm --filter @mymg/portal qa:cpu-gpu`。
