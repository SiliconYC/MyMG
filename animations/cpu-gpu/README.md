# CPU / GPU · 連續晶片剖視與真實任務流

GitHub Pages：`https://siliconyc.github.io/MyMG/#/cpu-gpu`

原生 React + Three.js，16 秒 / 30 FPS（480 幀）。固定世界座標中保留兩顆有金屬上蓋、封裝接點和矽晶粒的 3D 晶片。CPU 晶粒內有 2×2 四個大核心，GPU 晶粒內有 4×4 十六個小運算通道。

16 個灰色任務從 CPU 左邊進入晶粒、在核心被處理成藍色，並逐批離開；鏡頭自然橫移到 GPU，同樣 16 項任務一次同步完成。最後鏡頭拉遠，同時保留兩側完成的任務。**不再每換一幕就讓晶片突然出現，也不在 424 幀重置任務。**

三個關鍵視覺穩定性約束：

- CPU 與 GPU 均保持掛載和世界座標不變；所有鏡頭位移及縮放由連續曲線計算。
- 正交視野縮放為 67→40，留足畫面上下左右的晶片、接點與任務空間。
- 上蓋沿連續軌跡抬升後淡出，不在完成時突然取消元件。

保留一行字幕，不使用影片、連續圖片、進度儀表板、密集電路或閃爍粒子。晶片結構與時間比例均為教學示意，不是硬體規格和實測跑分。

驗收：`pnpm check`、`pnpm build:portal`、`pnpm --filter @mymg/portal qa:cpu-gpu`。
