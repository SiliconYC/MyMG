# CPU / GPU · 同一批可見任務

GitHub Pages：`https://siliconyc.github.io/MyMG/#/cpu-gpu`

原生 React + Three.js 動畫，20 秒 / 30 FPS，具備拖動時間軸、逐格和暫停功能。

一個灰色方塊代表一個要處理的獨立任務。**任務必須真的移動**：從待處理區出發，進入運算單元，在運算單元內變藍，最後離開並停在已完成區。

鏡頭敘事：
- 開場：先跟著單一任務走一次灰色→藍色的全程。
- CPU：同樣的 16 個任務經過四個大核心，分四批完成。
- GPU：同樣的 16 個任務經過 16 個小單元，同時開始、同時完成。
- 總覽：鏡頭拉遠後，兩個系統重新接收同樣一批任務，一邊分批、一邊並行。

畫面中僅保留一句階段說明，沒有額外進度條、數據面板、粒子和裝飾電路。芯片和任務的數量、耗時是示意而非跑分或硬件精確規格。不同工作負載的實際效率不能依據此動畫推斷。

測試：`pnpm check`；`pnpm build:portal`；`pnpm --filter @mymg/portal qa:cpu-gpu`。
