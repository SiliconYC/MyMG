# CPU / GPU · 晶片剖視與同一批可見任務

正式播放：`https://siliconyc.github.io/MyMG/#/cpu-gpu`。

原生 React + Three.js，20 秒、30 FPS。全部運動由影格決定，支援暫停與逐影格驗收。不使用錄影、貼圖影片或圖片取代 WebGL。

**晶片外觀**：兩顆方形積體電路封裝，各有單一矽晶粒、可辨識的封裝接點與活動揭開的金屬上蓋。CPU 晶粒內是 2×2 四個較大的核心，GPU 晶粒內是 4×4 十六個密集的輕量運算通道。CPU 的淡色區塊和快取條位於晶粒內，不再把不同區域畫成三條工廠輸送帶。

**任務流**：16 個中灰方塊由晶片左側進入矽晶粒，在核心上方縮小並變成藍色，從右側離開；CPU 四輪處理、GPU 一輪同步處理。鏡頭先介紹單個任務，再看 CPU 上蓋揭開及分批運行，再看 GPU 上蓋揭開與並行運行，最後拉遠同屏重播。

**少即是多**：只保留一句短字幕；不增加底圖網格、漂浮粒子、速度百分比、條形圖或密集線路。晶片結構、封裝、時間、任務數量均為教學示意，不代表實際微架構或跑分。

驗收：`pnpm check`、`pnpm build:portal`、`pnpm --filter @mymg/portal qa:cpu-gpu`。
